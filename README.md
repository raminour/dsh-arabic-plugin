# DSH Arabic Plugin | بلجن التعريب لـ DeepSeek Harness

بلجن (Plugin) مخصص لتعريب واجهة **DeepSeek Harness (DSH)** بالكامل، ودعم الكتابة من اليمين لليسار (RTL) لتحسين تجربة المستخدم العربي.

A plugin to fully localize and support Right-to-Left (RTL) Arabic interface for **DeepSeek Harness (DSH)**.

---

## ✨ المميزات | Features
*   ترجمة كاملة لواجهة البرنامج إلى اللغة العربية.
*   دعم اتجاه النص من اليمين لليسار (RTL).
*   سهل التثبيت والإزالة.

---

## 🚀 طريقة التثبيت | Installation

لتركيب البلجن، افتح **PowerShell** أو **CMD** واكتب الأمر التالي:

```bash
dsh plugin --profile desktop add dsh-arabic
