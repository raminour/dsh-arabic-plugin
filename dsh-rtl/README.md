# dsh-rtl — واجهة DeepSeek Harness من اليمين لليسار

بلوجن محلي صغير (client plugin) بيحوّل الواجهة لاتجاه RTL بدون تعديل ملفات البرنامج نفسها.
الطريقة دي هي المسار الرسمي لتحميل بلجنات في الـ Harness، وبالتالي **بتعيش بعد تحديث البرنامج** —
لأنها متخزّنة في بروفايل المستخدم (`~/.dsh`) مش جوه التثبيت.

## إيه اللي بيحصل بالظبط

| ملف | الدور |
|---|---|
| `package.json` | مانيفست الحزمة + إعلان `dsh.client` (platform: web) |
| `index.js` | النصف الخاص بالمضيف — فاضي، مجرد صف للودر |
| `client.js` | النصف الخاص بالمتصفح: بيحط `dir="rtl"` + `lang="ar"` على `<html>` ويلحق CSS صغير |
| `cordis.patch.yml` | سطر التفعيل (مرجعي — السكربت بيضيفه في بروفايلك) |
| `install-rtl.ps1` | تثبيت / إعادة تثبيت |
| `uninstall-rtl.ps1` | إزالة كاملة والرجوع لـ LTR |

الـ CSS بيحوّل الاتجاه ويسيب **جزر LTR** للكود والمسارات والـ `pre/code/kbd` والـ Monaco editor
عشان الكود ميتقلبش. أي حاجة داخل `input/textarea` بتستخدم `unicode-bidi: plaintext`
عشان العربي والإنجليزي يظهروا صح مع بعض.

## التثبيت (ويندوز جديد + Harness جديد)

1. نزّل DeepSeek Harness وافتحه مرة واحدة (عشان يعمل `%USERPROFILE%\.dsh\profiles\desktop`).
2. انسخ فولدر `dsh-rtl` ده لأي مكان دائم، مثلًا:
   `C:\Users\<user>\Documents\dsh-rtl`
3. من PowerShell 7:

   ```powershell
   pwsh -File .\install-rtl.ps1
   ```

   لو البرنامج شغال ومفيش تغيير: أعد تشغيله، أو:

   ```powershell
   pwsh -File .\install-rtl.ps1 -Restart
   ```

4. للتأكد: افتح البرنامج، لو السايدبار على اليمين يبقى تمام.

> البروفايل الافتراضي للبرنامج اسمه `desktop`. لو بتستخدم `dsh web` من الـ CLI:
> `pwsh -File .\install-rtl.ps1 -Profile web`

## الإزالة

```powershell
pwsh -File .\uninstall-rtl.ps1
```

بيشيل سطر التفعيل من `cordis.patch.yml` ويمسح `node_modules\dsh-rtl`.
بعدها أعد تشغيل البرنامج.

## ليه بلوجن مش تعديل `app.asar`؟

- `app.asar` جوه `Program Files`-ish ومحتاج صلاحيات، وأي تحديث للبرنامج بيمسح التعديل.
- `node_modules/dsh-rtl` + صف في `cordis.patch.yml` هو نفس مكان البلجنات الرسمية،
  وبيعيش بعد التحديثات وبعد إعادة تثبيت الويندوز (لو نقلت الفولدر وأعدت تشغيل السكربت).

## حدود معروفة

- الواجهة نفسها نصها إنجليزي/صيني — البلوجن بيقلب **الاتجاه** بس، مش بيترجم النصوص.
  (ترجمة عربي كاملة ممكنة بنفس النظام عبر `dsh-client-locale` + قاموس، لكنها شغل أكبر.)
- بعض العناصر المطلقة (قوائم منسدلة، تلميحات) ممكن تظهر على الجنب التاني — تعديلها
  بيتم بضبط CSS إضافي في `client.js` لو ظهرت مشكلة عملية.
- ملفات المصدر الأصلية في `app.asar` مش متلمسة خالص.
